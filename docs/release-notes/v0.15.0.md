## What's New in v0.15.0

Find an agent by its terminal ID in the Herdr sidebar and split your workspace to either side.

### ✨ New

- The left sidebar now lists agents and their subagents under **Agents**. Each row shows the full Herdr terminal ID, including the machine name for remote agents. Select a row to open its conversation, even when the agent has no tab or pane of its own.
- The **Split** menu opens a work pane to the left or right. When you split from a background agent’s chat, its running terminal gets a pane. Use **Chat** to return to the conversation and its reply draft.

### 🐛 Bug Fixes

- Fixed an issue where selecting a Codex agent could show an empty chat even though its conversation already existed (#17).
